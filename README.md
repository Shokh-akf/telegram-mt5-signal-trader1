📡 Telegram Signal → MT5 Auto Trader

An automated trading program that receives trading signals from a Telegram signal channel and executes them automatically on MetaTrader 5.

🚀 Main Features

* 📡 Automatically receives signals from a Telegram channel
* 📈 Supports BUY and SELL signals
* ⚡ Automatically executes trades in MT5
* 🔢 Opens up to 4 orders for one signal
* 🛡️ Automatically sets Stop Loss (SL)
* 🎯 Takes Take Profit (TP) levels directly from the signal
* 🛑 Supports SAVE signals to close all active orders
* 🔄 Automatically manages multiple positions
* ⚙️ Designed for fast signal execution
* 📊 Works with MetaTrader 5

🔥 Example

When a signal such as:

BUY NOW

is received from the Telegram signal channel, the program automatically executes the configured trades in MT5.

For example:

BUY NOW → 4 orders opened

The system then automatically applies the required SL and TP according to the signal and program settings.

When a SAVE signal is received, the program can automatically close all active positions.

The goal is to eliminate manual trade execution and allow Telegram signals to be executed quickly and automatically in MetaTrader 5.
