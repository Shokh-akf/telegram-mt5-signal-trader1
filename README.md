📡 Telegram Signal → MT5 Auto Trader

Automated Telegram Signal Trading System for MetaTrader 5

A Python-based automation program that receives trading signals from a Telegram signal channel and automatically executes them on MetaTrader 5.

The system is designed to reduce manual trading and execute signals quickly and consistently.

⸻

🚀 Main Features

📡 Telegram Signal Detection

Automatically monitors a Telegram signal channel and detects supported trading signals.

📈 BUY / SELL Execution

Automatically processes BUY and SELL signals and sends trades to MetaTrader 5.

🔢 Multiple Orders

One signal can automatically open up to 4 orders according to the configured settings.

🛡️ Automatic Stop Loss

Stop Loss can be automatically applied according to the signal and system configuration.

🎯 Take Profit

Take Profit levels are automatically taken from the Telegram signal and applied to the corresponding MT5 orders.

🛑 SAVE Signal

When a SAVE signal is received, the system can automatically close active positions.

⚡ Fast Execution

The system is designed to process Telegram signals and execute trades automatically without requiring manual order entry.

⚙️ MT5 Integration

The program communicates with MetaTrader 5 for automated trade execution and position management.

⸻

🔄 How It Works

Telegram Signal Channel
          ↓
   Python Auto Trader
          ↓
      Signal Parser
          ↓
       MetaTrader 5
          ↓
   Automatic Orders

Example

When the Telegram channel sends:

BUY NOW

The program can automatically:

1. Detect the signal
2. Identify the trading direction
3. Connect with MetaTrader 5
4. Open up to 4 configured orders
5. Apply Stop Loss
6. Apply Take Profit from the signal
7. Manage the active positions

If the channel sends:

SAVE

The program can automatically close the active positions according to the configured rules.
